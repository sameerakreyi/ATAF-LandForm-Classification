# ATAF-LandForm Classification Framework
Multi-Criteria DEM-Based Terrain Classification

**Developer:** Asst.Prof. Dr. Sameer S. Akreyi @2026

## How to Use
1. Open [Google Earth Engine Code Editor](https://code.earthengine.google.com)
2. Copy `ataf_landform_classification.js` and paste into editor
3. Enter your FeatureCollection Table ID
4. Select DEM source
5. Click RUN CLASSIFICATION
